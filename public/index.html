What this lab models

A digital workbench.
Not a physical circuit solver.

Logic & timing
VHDL compiled and executed by the installed GHDL engine, connected through a native VPI bridge. When no SDF annotation is present, GHDL can also synthesize the design into an RTL stepper for high-frequency burst execution. Nine-state logic, native assertions, event timing, ideal clock stimulus and native VCD capture. The website itself is not a certified verification tool.
Board visualization
Photo-referenced component layout, active-low keys and LEDs, and multiplexed display persistence. The model is illustrative, not a dimensionally certified CAD model.
Not simulated
Voltage, current, power consumption, analog transients, signal integrity, metastability, thermal behavior, or FPGA place-and-route timing. Peripheral chips are visual references, not complete electronic models.
Files & projects
VHD/VHDL and VHO netlists compile locally; vendor netlists require their matching VHDL primitive libraries. CF files are GHDL indexes: include their source files and set the correct libraries. QPF/QSF open or save native Quartus-style projects; QSF imports pin assignments, not a Quartus build. MD files display as documentation. SDF requires matching VITAL timing models and an instance path. HEX/MIF/MEM/TXT/DAT files are provided to the testbench as data; they do not configure the FPGA. VCD replays digital and real traces with selectable board scope. User-supplied Verilog/SystemVerilog and proprietary bitstreams cannot execute in this GHDL installation.
Resource limits
Four simultaneous simulations, 100 source/data files, 512 observed native signals, 4096 bits per signal, 16 hierarchy levels. Live sessions use rolling in-memory VCD history (up to 25,000 timestamps) so continuous runs never hit disk-file size limits; the on-screen analyzer keeps a separate 10,000/40,000/100,000-sample rolling window per signal, and VCD replay accepts 32 MB and 250,000 timestamps. Native simulation runs up to ~5 hours of 64-bit femtosecond time per session; the GHDL/VPI path burst-steps high-frequency clocks up to 131,072 cycles per frame, while the compiled RTL runner can step up to 2,500,000 cycles per frame.
Local execution
Run only trusted HDL. GHDL testbenches execute locally and may access files; this workbench is not a security sandbox. Projects autosave in this browser and can be exported as JSON; simulation processes and waveform history are not restored after closing the page.
Physical hardware
No JTAG connection. SOF/POF files are inspected, never “programmed.” Verify pin assignments and I/O standards against your exact board schematic before using real hardware.
